# متجر وموقع برونت كمبيوتر | ProNet Computer Store & WebPage

**برونت كمبيوتر (ProNet Technology For Computer) — خدمات بإتقان**  
المتجر الإلكتروني، بوابة حلول الشركات والمناقصات (B2B)، ولوحة التحكم الشاملة (Admin CMS).

---

## 📁 هيكلة ملفات المشروع (`ProNet_Store_WebPage`)

- `index.html` : الصفحة الرئيسية الكاملة للموقع والمتجر الإلكتروني مع لوحة التحكم (جاهزة للرفع المباشر على GitHub Pages أو أي استضافة ويب).
- `pronet_store.html` : نسخة مستقلة ذاتياً (Standalone Single-File) تعمل مباشرة بدون إنترنت.
- `css/style.css` : ملف التنسيقات والهوية اللونية الرسمية لبرونت كمبيوتر (`#00A8FF`, `#38B6FF`, `#0D1B2A`, `#D4AF37`).
- `js/app.js` : الشفرة البرمجية للمتجر، محرك العملات (`USD` / `YER` / `SAR`)، سلة المشتريات، генератор عروض الأسعار PDF، ولوحة التحكم.
- `data/store_data.json` : قاعدة بيانات المتجر (الأصناف، الأسعار، الأقسام، الماركات، المنشورات، وإعدادات سعر الصرف).
- `data/pronet_products_catalog.csv` : جدول كتالوج الأصناف والأسعار بصيغة متوافقة مع Microsoft Excel و Google Sheets.
- `assets/hero_banner.jpg` : صورة البنر الرئيسي للمعرض.
- `assets/logo.svg` : شعار برونت كمبيوتر الرسمي بصيغة الفيكتور (SVG).

---

## ⚙️ مميزات لوحة التحكم (Admin CMS)

1. **إدارة الأصناف والأسعار**: إضافة، تعديل، وحذف الأصناف مع إمكانية تعديل السعر مباشرة أو إخفاء السعر وتفعيل زر *"تواصل لمعرفة السعر"*.
2. **محرك العملات المتعددة**: التبديل الفوري بين الدولار الأمريكي (`USD`)، الريال اليمني (`YER`)، والريال السعودي (`SAR`) مع تحديث سعر الصرف من لوحة التحكم.
3. **إصدار عروض الأسعار والطلبات**: إرسال سلة المشتريات أو طلبات الشركات (RFQ) مباشرة إلى واتساب المبيعات أو طباعة عرض سعر رسمي (PDF).
4. **المزامنة المباشرة مع GitHub**: دعم التحديث المباشر إلى مستودع `ProNetComputer/ProNet_Store` أو تصدير ملف `index.html` المحدث بضغطة زر.
