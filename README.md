# موقع ومتجر برونت كمبيوتر | ProNet Computer (الإصدار المطور v2)

**برونت كمبيوتر (ProNet Computer) — خدمات بإتقان**
- **الإدارة العامة**: المهندس عمار محمد سعيد الأسدي — المدير التنفيذي - ProNet Computer

## أبرز التحديثات المنفذة في هذا الإصدار:
1. **اعتماد الشعار الرسمي المرفق (`assets/ProNet_Logo.png`)** في الهيدر، الفوتر، صفحة من نحن، عروض الأسعار، وبوابة الإدارة.
2. **تحديث التبويبات والأقسام والواجهة الرئيسية** على غرار هيكلة موقع ومتجر شركة الشهاب تك (`alshihabtec.com`):
   - سلايدر صور متحرك (Hero Image Carousel) بـ 3 شرائح احترافية.
   - شريط الماركات العالمية مع الشعارات (Brand Logos Bar) مباشرة تحت السلايدر الرئيسي.
   - تبويبات: `الرئيسية`، `من نحن`، `مجالات العمل`، `المتجر الإلكتروني`، `المشاريع والمناقصات`، `المدونة والمنشورات`، `تواصل معنا والدفع`.
3. **تحديث بيانات الإدارة العامة، أرقام الجوال والواتساب (المبيعات والإدارة)، وطرق الدفع والحسابات البنكية** (كاك بنك، بنك التضامن، بنك القطيبي الإسلامي، بنك الكريمي الإسلامي).
4. **إخفاء لوحة التحكم وفصلها في صفحة مستقلة (`admin.html` أو `/admin` أو `#/admin`)** مع نظام تسجيل دخول وصلاحيات مخصصة:
   - **المصمم (`designer`)**: كامل الصلاحية.
   - **الإدارة (`management`)**: كامل الصلاحية.
   - **المبيعات (`sales`)**: إدارة الأصناف، التسعير، والعروض.
   - **الدعم الفني (`support`)**: إدارة المواصفات الفنية، المشاريع، وتذاكر الصيانة والدعم الفني.
